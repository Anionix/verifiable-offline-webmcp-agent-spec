# Security and Privacy

Threats include prompt/tool/page injection, privilege amplification, forged approval, duplicate effect, ambiguous retry, audit rewriting, excessive data collection, stale-policy replay, and supply-chain drift. Controls are fail-closed hard gates, exact intent-bound approval, planner capability minimization, secret isolation, reconcile-before-retry, signed external checkpoints, and digest/reference-oriented audit storage.
