# Implementation Plan

Phase 0 freezes Canonical IR and formal invariants. Phase 1 ships local/offline intent, cache, queue, rules, and per-device events. Phase 2 adds the WebMCP adapter and read-back evidence. Phase 3 adds optional Responses planning with privacy/cost routing. Phase 4 adds sync, checkpoints, and conflicts. Phase 5 calibrates reliability, verification error, and class-specific SLO policy.

Done means schema-valid assets, passing TypeScript vectors, reproduced Wolfram formulas, zero baseline safety violations, mutation-test sensitivity, valid audit proofs, and no private key in the repository.
