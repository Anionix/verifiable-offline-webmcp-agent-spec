# ADR-011 — Use a JSON-LD/PROV-O/DCAT-inspired knowledge graph without claiming conformance to a single official Open Knowledge Format / JSON-LD/PROV-O/DCAT風の知識グラフを採用するが、単一の公式Open Knowledge Format適合は主張しない

- **Status:** `accepted`
- **Stable UUIDv5:** `df667551-a3b4-5140-a293-f6c41fc493c8`
- **Occurrence UUIDv7:** `01a04291-b3b3-7493-979a-51788c43cff2`
- **Source refs:** SRC-JSONLD-2020, SRC-PROVO-2013, SRC-DCAT3-2024

## Decision / 決定

**JA:** JSON-LD/PROV-O/DCAT風の知識グラフを採用するが、単一の公式Open Knowledge Format適合は主張しない

**EN:** Use a JSON-LD/PROV-O/DCAT-inspired knowledge graph without claiming conformance to a single official Open Knowledge Format

## Consequences / 帰結

**JA:** 安全境界と実装責任が明確になる。

**EN:** Safety boundaries and implementation responsibilities become explicit.
