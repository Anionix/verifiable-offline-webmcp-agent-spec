# Glossary

| Term | Meaning |
|---|---|
| authority | Permission to legalize execution; distinct from planner confidence. |
| belief | Probability distribution over hidden world state. |
| commit | Final acceptance of a verified external effect. |
| evidence | Read-back, receipt, state diff, or observation supporting/refuting an effect. |
| hard gate | A false condition removes an action from the feasible set. |
| intent | Normalized tool, arguments, target, scope, amount, expiry, and identity. |
| reconcile | Re-observe the external world to establish an unknown effect. |
| UUIDv5 | Deterministic namespace/name identity. |
| UUIDv7 | Unix-millisecond time-ordered occurrence identifier. |
