Verify it in three checks

  1. Find one tool.Open this page in ChatGPT’s in-app browser, or Chrome with WebMCP testing enabled. The available tool must be notify_once.
  2. Run the shown prompt.The page must reach DRY_RUN / NOT_STARTED, show effect count 0, and enable the human approval button.
  3. Repeat the operation.The UUIDv5 intent stays the same. No automatic notification is allowed; the effect-start count can never exceed 1.

Evidence boundary: deterministic build checks pass locally. Model-choice accuracy is UNMEASURED; the repeatable cases are published in webmcp-evals.json.
